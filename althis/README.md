# World Chronicle

架空世界・オルタナティブヒストリー用のローカルWebアプリMVP。

## 主機能
- 国家 / 地域 / 人物 / イベント / 外交関係
- 開始年・終了年を持つ時間付きデータ
- 指定年の世界状態表示
- 年表
- 横断検索
- 基本的な整合性チェック
- JSON完全バックアップ / 復元
- CSV書き出し
- localStorage保存
- PWA対応

## iPhoneで使う
GitHub Pages / Cloudflare Pages / Netlify 等にこのフォルダを置き、Safariで開いて「共有」→「ホーム画面に追加」。

## 次の拡張候補
政権・政党・選挙・条約、因果リンク、史実との差分、人口・民族・言語・宗教、年代別地図。
